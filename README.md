# FieldShift — NASA Space Apps Challenge 2026

**Challenge:** Field Shift: Adapting Farms With NASA Data

A responsive single-page prototype for AgroSpace Xcel, built for GitHub Pages.

## Included
- NASA-inspired Earth observation visual direction using the supplied orbital Earth photo.
- Four main sections: Home, Method to Use, Navigating, Meet our Team.
- Interactive Leaflet map: click to drop a field pin.
- NASA POWER API integration for temperature, precipitation and root-zone wetness when the browser can reach the API.
- Demo fallback so the interface remains usable during presentations if the API is unavailable.
- Exactly the five supplied team portraits; no external team photos.

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `styles.css`, `script.js`, `README.md`, and the `assets` folder.
3. In GitHub: Settings → Pages → Deploy from branch → choose `main` and `/ (root)`.
4. Open the generated Pages URL.

The map tiles and NASA POWER data require an internet connection in the browser.
